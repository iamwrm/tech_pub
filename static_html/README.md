# static_html

Self-contained HTML pages. GitHub only shows them as source; to open one as a rendered page, use [raw.githack](https://raw.githack.com/).

Take the file's GitHub URL and swap the host, dropping `/blob`:

```
https://github.com/iamwrm/tech_pub/blob/main/static_html/image_compressor.html
https://raw.githack.com/iamwrm/tech_pub/main/static_html/image_compressor.html
```

- `raw.githack.com/...` follows the branch; after a push it can take a few minutes to update (hard-refresh).
- For a permanent link pinned to one version, use `rawcdn.githack.com` with a commit hash instead of the branch:
  `https://rawcdn.githack.com/iamwrm/tech_pub/<commit>/static_html/image_compressor.html`
